# ThePrivator 3.2.0

This release promotes the verified 3.1.x iterations, including the generated-profile Google sign-in fix confirmed on Linux Mint.

## Highlights

- Import and export multiple profiles in one batch.
- Paste proxies as `host:port:user:pass`.
- Optionally protect local profile data with PIN/password encryption.
- Copy text from notes bubbles; edit notes in profile settings.
- See operating system, architecture, and Chrome version in the profile list, plus application disk usage in the footer.
- Keep themes and settings across Linux restarts.

## Fixes

- Ordinary managed launches use a nonzero local debugging port, avoiding Chromium's unintended automation indicator while preserving generated fingerprints. Explicit automation launches keep their existing behavior.
- Generated identity overrides persist across browser tabs and frames.
- Cross-site frames, shared-renderer locale replies, and closing targets no longer trigger the previously observed browser shutdowns.
- Last-launched timestamps update correctly; proxy-check results survive tag and note edits.
- User-agent refresh works during profile creation.
- Linux packaging uses an Ubuntu 22.04 baseline for Mint compatibility.
- The temporary Compatible managed preset has been removed.

## Upgrade notes

- Stop running profiles and close ThePrivator before installing the update.
- Profile store version 5 preserves existing profile data. Older versions must not write the migrated store.
- Vault protection is optional. Data is decrypted while unlocked; an interrupted session can leave plaintext until recovery and locking. There is no forgotten-password reset.
- Exported packages omit proxy passwords. Exported or externally synced browser data is outside local vault encryption.
- Google sign-in was confirmed by the user for the reported generated-profile case on Linux Mint. Other accounts and configurations may behave differently.
